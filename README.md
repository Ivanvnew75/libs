# libs

Общие пакеты микросервисов приложения mood-bot (курс «12 Factor App»).

* `common` — чтение конфигурации из окружения (Фактор 3), структурированный
  логгер в stdout (Фактор 11), graceful shutdown по SIGTERM (Фактор 9),
  HTTP-клиент с таймаутом и ретраями с джиттером.

Сюда кладётся только то, что меняется редко. Бизнес-логика в общую
библиотеку не выносится: иначе микросервисы превращаются в распределённый
монолит, где ни один нельзя выкатить отдельно.

Версионируется тегами: `git tag v0.1.0 && git push --tags`, потребители
подтягивают через `go get github.com/Ivanvnew75/libs@v0.1.0`.
